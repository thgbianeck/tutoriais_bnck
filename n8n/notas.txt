O padrão correto que deve ser seguido no documento é este:

O documento inteiro fica dentro de ```markdown (abre) e ``` (fecha)
Blocos internos de código SQL, java, javascript e outras linguagens usam ~~~ abrindo e fechando
Blocos internos de texto puro usam ~~~text e ~~~
Blocos internos de diagrama usam ~~~mermaid e ~~~
Nenhum bloco interno usa triple backtick ```
Não quebre linhas de parágrafos, a não ser que seja necessário para a formatação do markdown ou para a clareza do texto.
Use negrito para destacar palavras-chave, conceitos importantes e comandos.
